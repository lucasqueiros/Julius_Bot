# Julius - Assistente Financeiro

Bot do Telegram integrado com Gemini API e Notion para gerenciar suas finanças pessoais de forma inteligente.

# Funcionalidades
- Recebe transações via mensagens de texto
- Processa informações usando IA (Gemini API)
- Salva automaticamente no Supabase
- Identifica tipo (Receita/Despesa), valor, categoria e descrição
- Visualiza de forma intuitiva via Streamlit
